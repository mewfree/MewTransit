#+title: MewTransit
#+description: Montreal public transit app

Map-first Expo app. Nearby STM / REM / EXO stops, next departures.

TODOs and the long list of later ideas live in [[file:project.org][project.org]].
The API is a sibling repo: [[file:../mewtransit-api/readme.org][mewtransit-api]].

* Run
~npx expo start~

Talks to ~https://mewtransit-api.dgonot.workers.dev~ by default.
Override with ~EXPO_PUBLIC_API_URL~ (e.g. ~http://127.0.0.1:8787~ for a local worker).

* Stack
- Expo SDK 57
- Expo Router
- expo-location
- react-native-maps

* Build
- Android: ~eas build --platform android~
- iOS: ~eas build --platform ios~
